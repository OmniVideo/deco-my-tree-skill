# Deco My Tree Skill

SKILL.md for [Deco My Tree](https://decomytree.net/) — a free online Christmas tree friends can decorate with sealed wishes.

## What it does

- Helps set up a shareable online Christmas tree
- Explains how guests hang ornaments and leave sealed wishes
- Points assistants to the live tool at https://decomytree.net/

## Install

```bash
git clone https://github.com/OmniVideo/deco-my-tree-skill.git
```

Then load `SKILL.md` in your Claude Code / Codex skills directory, or follow your assistant's skill install steps.
